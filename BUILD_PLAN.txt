================================================================================
HORSE RACING SIMULATOR - DESIGN
================================================================================
Last updated: 2026-10-21
This is the design. Code lives in public/js. See README.md to run it.
The first version was pygame. It was replaced by this web version.
The last commit with the Python code is 6d61b31.


1. GOAL
--------------------------------------------------------------------------------
A party game. A stable of 64 horses. A day of 8 races, 8 horses each.
The operator pre-sets who runs in each race. Between races they take names and
bets. Then the race plays out on an oval, results show, bets pay out.

Hosted as a Cloudflare Worker that serves static files. All logic runs in the
browser. One operator, one screen.


2. FLOW
--------------------------------------------------------------------------------
  menu -> betting -> setup -> race -> results -> (betting again, or summary)

  menu      title, start the card
  betting   pick horses, enter player # + name + wager, live odds, undo
  setup     horses line up at the gate. "Go!" starts a 3-2-1 countdown
  race      ~30 s animation. click skips. gun, hooves, crowd, finish board
  results   finish order + payouts counting up. refund if nobody hit
  summary   total payouts per player over the card


3. RACE MATH
--------------------------------------------------------------------------------
Each horse has a fixed average speed. Speeds are squeezed toward the roster
mean (SPEED_COMPRESSION) so races stay close.
A race samples each horse's speed from Normal(average, SPEED_SIGMA).
Finish time = distance / speed. Sort for the order.

Displayed win chance is softmax over average speeds (PROB_TEMPERATURE).
Exact-order chance is sequential Plackett-Luce on the same weights.

The animation gives each horse its own random pace curve (slow start, late
kick, front-runner or closer). The curve is normalized, so it never changes who
wins. It only makes horses pass each other.
Lanes are staggered so every horse runs the same distance.


4. BETTING
--------------------------------------------------------------------------------
Player number + optional name. Names stick to numbers across races.
One horse = win bet. 2 or 3 horses in order = parlay.
Same player + same pick adds to the existing bet.

Zero house take. The whole pool is paid to winning tickets.
A ticket's share = stake / chance it hits. Parlays get a bonus
(1.25x for 2 legs, 1.5x for 3) so they pay more per dollar.
If nobody hits, every stake is refunded.


5. CODE LAYOUT
--------------------------------------------------------------------------------
  public/index.html     one canvas
  public/js/
    settings.js         constants: sizes, horses per race, speeds, sound mix
    roster_raw.js       the 64 horses
    horses_data.js      roster + compression, horse objects
    race_card.js        which horses run in which race. edit by hand
    race.js             honest: sampling, probabilities, pace curves
    betting.js          honest: pool, odds, settlement
    track.js            honest geometry + drawing the oval
    crowd.js            crowd build + pass detection (honest) + drawing
    sprites.js          horse + starter drawing
    sounds.js           synth + WebAudio
    game.js             state machine + all six screens
    main.js             loop
  test/                 node tests
  wrangler.jsonc        Worker config (assets only)

Honest = no DOM, no canvas, no clock. Plain values in, plain values out.
Those are the ones with tests.
